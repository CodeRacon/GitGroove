# GitGroove

GitGroove macht aus dem GitHub Contribution Grid eine spielbare Klangfolge. Du gibst ein Profil ein, wählst einen Abschnitt im Raster und hörst, was aus den Beiträgen wird.

## Vom Kalender zur Musik

Eine Kalenderwoche wird zu einem 4/4-Takt. Ihre sieben Tage liegen als gleichmäßige Schritte darin. Tage ohne Beiträge lösen keine neuen Töne aus; an aktiven Tagen setzt der Bass ein. Mit mehr Beiträgen kommen Pad-Akkorde und kleine Melodien der Lead-Stimme hinzu. Auch die Anschlagstärke und die Akkordfolge reagieren auf die Daten im Raster.

Solange Profil, Beitragskalender und gewählter Abschnitt gleich bleiben, entsteht dieselbe Folge von Noten. Der Playhead zeigt währenddessen, welcher Tag gerade dran ist.

Du kannst den Abschnitt verschieben, das Tempo ändern und Bass, Pad und Lead im Klang anpassen, stummschalten oder solo hören. Das Raster bleibt dabei die Grundlage: Es bestimmt, wann etwas spielt und wie viel musikalisch passiert.
